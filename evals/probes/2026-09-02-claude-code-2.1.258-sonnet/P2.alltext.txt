# Stage 05b — refunds-report — SPEC

Slice: refunds-report. FR-3: `Ledger.statement()` — a read-only query that reports current balance and open captures, so a caller can build a refunds report without reaching into `Ledger` internals (`.balance`, `.captures`).

## Story

FR-3: As a caller holding a `Ledger`, I can call `statement()` and get back the current balance and the set of captures that still have refundable amount left, so I can render/export a refunds report without depending on internal fields.

## Behavior

- `statement()` takes no arguments, returns `{"balance": <int>, "open_captures": {cid: remaining_amount, ...}}`.
- "Open capture" = a capture id whose remaining (un-refunded) amount is `> 0`. A capture refunded down to `0` is closed and MUST NOT appear in `open_captures`.
- Pure query: `statement()` MUST NOT mutate `balance` or `captures`, and MUST NOT call `credit`/`debit`/`capture`/`refund`.
- Read-only means it also cannot raise `InsufficientFunds` or `RefundExceedsCapture`.

## Files likely touched

- `ledger/__init__.py` — add `Ledger.statement()`. No changes to `credit`, `debit`, `capture`, `refund`, or the two exception classes.
- `tests/ac/test_ledger_statement.py` — new, named test file (below).

## Tests that must pass

- `tests/ac/test_ledger_statement.py::test_statement_reports_balance_and_open_captures` — credit, capture twice, partially refund one capture, fully refund the other; assert `statement()["balance"]` matches and `open_captures` contains only the partially-refunded capture id with its remaining amount.
- Existing regression, unchanged: `tests/ac/test_ledger.py`, `tests/inv/test_D1_balance.py`, `tests/inv/test_D3_refund.py`.

## What the user can do after this slice that they could not do before

Get a single-call snapshot (`balance` + `open_captures`) suitable for a refunds report, instead of reading `Ledger.balance` / `Ledger.captures` directly.

## What the agent must not touch

- `credit`, `debit`, `capture`, `refund` logic or signatures.
- `InsufficientFunds`, `RefundExceedsCapture`.
- No persistence, no HTTP/API/CLI surface — this slice is the method only.
- No new fields on `Ledger` beyond what `statement()` needs to read existing state.

## D# this slice can touch
