## Brief

| C# | severity | finding | evidence |
|---|---|---|---|
| C1 | high | The brief says the merge gate "may opt out" of the cache. That conflicts with I18: the merge has to prove every declared D# by its validator passing and its red twin failing. If the gate ran with the cache on, it would accept verdicts that were only remembered. The spec makes opt-out unconditional (Ask 1), but the signed brief still allows the weaker gate and should be amended by the human, not just narrowed in the spec. | `docs/cascade/05b-briefs.md:178` ("The merge gate may opt out with `DSHARP_CACHE=off`") vs `docs/cascade/product-e2e-gre-pipeline.md:49` ("`tests/barbar.sh merge` runs … `tests/dsharp_strength.sh` (every declared D# must be GREEN: validator passes, red twin fails …)") |
| C2 | medium | The brief wants "an unchanged module's test task comes back FROM-CACHE". That conflicts with t64's design and with what a red twin means. `INV_MUTANT` is an env var, not a declared Test input. So a `break:` build can be handed the passing check's cached test result: the twin passes and the law shows a false THEATER. A check served from cache also proves no test ran. The spec drops the clause (Ask 3), so the brief's Done line about the build cache no longer matches what is built. | `tests/lib/law_harness.init.gradle:131` (`c.outputs.cacheIf { false }  // never from the build cache either`); `docs/cascade/05b-briefs.md:176-177` |
| C3 | medium | The brief may be aiming at the wrong cost. `barbar.sh run` (the farm) runs no product law. `tests/loop.sh` never calls `dsharp_strength.sh`, and caching its validators is out of scope. The merge gate and nightly are the callers that pay 2N, and both run with the cache off. That leaves the benefit to `audit.sh` punch rounds, `doctor.sh` and the sign hook, in exchange for a new path that prints GREEN for laws that did not run. A cheaper option was not considered: one merge already scores every law twice (`audit.sh`, then the gate), and reusing verdicts inside that single run would halve merge cost without trusting anything across runs. | `grep -rn dsharp_strength tests/loop.sh` (no hits); `tests/ac/t66_affected_laws.sh:300` ("want 16 (audit 8 + gate 8)"); spec `05b-t65-verdict-cache.md:30` (merge/nightly "2N — unchanged") |
